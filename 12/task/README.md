# Задание 12. Отобрать чётные числа

В файле `main.py` создайте функцию: `get_even(values)`.

Функция возвращает новый список чётных чисел из переданного списка целых чисел. Порядок и повторы подходящих элементов сохраняются, исходный список не меняется. Если совпадений нет или исходный список пуст, результат — новый пустой список. После вызова покажите результат и исходные данные. Например, [-4, 3, 0, 6, 6, 7] дают [-4, 0, 6, 6].

Данные для показанных вызовов задайте в программе; ввод с клавиатуры не нужен.
Имена, комментарии и текст в коде пишите на английском. Вывод сопровождайте английскими
подписями или понятными сообщениями. Формулировки выбирайте сами: текст примера — один
из возможных вариантов, дословное совпадение не требуется.

## Пример вывода

```text
Even values: [-4, 0, 6, 6]
Original values: [-4, 3, 0, 6, 6, 7]
```
