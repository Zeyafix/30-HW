# Задание 03. Один обязательный параметр

В файле `main.py` создайте функцию: `show_number(number)`.

Функция принимает один обязательный параметр и выводит переданное число с пояснением. Вызовите её три раза: передайте число прямо в вызове, затем переменную с числом, затем результат арифметического выражения. Данные выберите сами, например, 7, значение переменной 12 и 3 + 5.

## Пример вывода

```text
Number: 7
Number: 12
Number: 8
```
