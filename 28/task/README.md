# Задание 28. Поиск книг

В файле `main.py` создайте функцию: `find_books(titles, query)`.

Функция принимает список английских названий книг и поисковую строку. Верните новый список названий, в которых встречается query без учёта регистра. Искомый текст может быть частью слова. В результате сохраняются исходное написание названий, порядок и повторы. Исходный список не меняется. Пустая поисковая строка подходит ко всем названиям. Если совпадений нет или список пуст, верните новый пустой список. Покажите вызов, результат и исходные названия. Для ["Python Basics", "Garden Stories", "PYTHON Practice"] найдите "pYtHoN".

## Пример вывода

```text
Found books: ['Python Basics', 'PYTHON Practice']
Original titles: ['Python Basics', 'Garden Stories', 'PYTHON Practice']
```
