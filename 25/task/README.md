# Задание 25. Корректировка цен

В файле `main.py` создайте функцию: `adjust_prices(prices, percent=5)`.

Функция изменяет каждую цену в переданном списке на percent процентов. По умолчанию цены увеличиваются на 5%. Положительное значение означает увеличение, отрицательное — уменьшение, ноль — отсутствие изменения. Пустой список допустим. Сохраняйте порядок, не округляйте цены внутри функции, возвращаемое значение не требуется. Покажите вызов с умолчанием и с другим процентом на двух независимых списках [100, 200], затем выведите оба изменённых списка. Например, другой процент — -10.

## Пример вывода

```text
Default adjustment: [105.0, 210.0]
Custom adjustment: [90.0, 180.0]
```
