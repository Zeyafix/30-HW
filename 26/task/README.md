# Задание 26. Завершённые дела

В файле `main.py` создайте функцию: `remove_task(tasks, completed)`.

Функция удаляет из исходного списка дел все вхождения указанного названия completed. Названия на английском сравниваются точно, с учётом регистра. Остальные дела сохраняют порядок. Если названия нет или список пуст, ничего не меняется и ошибки нет. Возвращаемое значение не требуется. Покажите несколько вызовов: удаление повторяющегося дела и попытку удалить отсутствующее. Например, в ["read", "read", "walk", "read"] завершено read, а cook отсутствует. После каждого вызова выведите список.

## Пример вывода

```text
After completion: ['walk']
After missing task: ['walk']
```
