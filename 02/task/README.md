# Задание 02. Три разделителя

В файле `main.py` создайте функцию: `show_separator()`.

Создайте функцию без параметров, которая выводит строку-разделитель. Выведите четыре разных сообщения на английском и вызовите функцию три раза: между первым и вторым сообщениями, между вторым и третьим, между третьим и четвёртым. Вид разделителя выберите сами.

## Пример вывода

```text
Stage: Start
----------
Stage: Load
----------
Stage: Process
----------
Stage: Finish
```
