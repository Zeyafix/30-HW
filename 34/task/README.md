# Задание 34. Отчёт о тренировках

В файле `main.py` создайте функции: `get_long_workouts(durations, min_minutes=20)`, `summarize_workouts(durations)`.

Разделите подготовку отчёта между двумя функциями:

- `get_long_workouts` возвращает новый список продолжительностей тренировок не короче `min_minutes`,
  по умолчанию 20 минут. Продолжительности и порог неотрицательные, возможны дробные значения.
  Сохраняйте порядок и повторы, исходный список не меняйте. При отсутствии совпадений,
  в том числе для пустого списка, верните новый пустой список.
- `summarize_workouts` возвращает количество тренировок и суммарное время, именно в таком порядке,
  не меняя переданный список. Для пустого списка оба значения равны нулю.

Свяжите вызовы: передайте результат отбора функции отчёта и распакуйте итог в две переменные.
Покажите количество, время, отобранный и исходный списки. Повторите расчёт с другим порогом.
Для `[10, 20, 35, 20]` умолчание оставит три тренировки на 75 минут,
порог 30 — одну на 35 минут.

## Пример вывода

```text
Selected workouts: [20, 35, 20]
Workout count: 3
Total minutes: 75
Custom workouts: [35]
Custom count: 1
Custom minutes: 35
Original durations: [10, 20, 35, 20]
```
