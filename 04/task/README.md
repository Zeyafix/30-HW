# Задание 04. Порядок аргументов

В файле `main.py` создайте функцию: `show_pair(first, second)`.

Функция принимает два обязательных параметра и выводит сначала first, затем second. Вызовите её два раза с двумя разными числами: во втором вызове поменяйте позиционные аргументы местами. По выводу должно быть видно, какое значение передано первым, а какое вторым.

## Пример вывода

```text
First: 4; second: 9
First: 9; second: 4
```
