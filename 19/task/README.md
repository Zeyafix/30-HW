# Задание 19. Подпись к посылке

В файле `main.py` создайте функцию: `show_address(name, city, address)`.

Функция принимает имя получателя, город и адрес и выводит почтовую подпись со всеми тремя значениями. Все параметры обязательные. Подготовьте подписи хотя бы для двух посылок с разными получателями и адресами. Все данные запишите на английском. Порядок строк и текст пояснений выберите сами.


## Пример вывода

```text
Recipient: Alice
City: Baku
Address: 12 Garden Street
Recipient: Ben
City: London
Address: 7 Park Road
```
