# Задание 29. Проходной балл

В файле `main.py` создайте функцию: `get_passed(scores, threshold=60)`.

Функция возвращает новый список результатов не ниже threshold. По умолчанию порог равен 60 баллам. Баллы и порог — от 0 до 100 включительно. Сохраняйте порядок и повторы. Исходный список не меняйте. При отсутствии совпадений, в том числе для пустого списка, возвращайте новый пустой список. Покажите вызовы с умолчанием и другим порогом, оба результата и исходные данные. Для [59, 60, 85, 60, 100] сравните пороги 60 и 85.

## Пример вывода

```text
Default threshold: [60, 85, 60, 100]
Custom threshold: [85, 100]
Original scores: [59, 60, 85, 60, 100]
```
