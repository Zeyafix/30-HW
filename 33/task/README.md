# Задание 33. Подготовка списка гостей

В файле `main.py` создайте функции: `add_guest(guests, name)`, `get_guests_by_letter(guests, letter)`.

Функции работают с одним списком гостей:

- `add_guest` добавляет имя в конец исходного списка, если такого имени ещё нет.
  Имена на английском сравниваются точно, с учётом регистра. Существующие записи сохраняются.
  Возвращаемое значение этой функции не требуется.
- `get_guests_by_letter` возвращает новый список имён, начинающихся с заданной буквы без учёта регистра.
  `letter` — одна английская буква, имена непустые. Сохраняйте исходное написание, порядок и повторы
  подходящих имён, не меняйте список при фильтрации. Пустой список допустим.
  При отсутствии совпадений результат — новый пустой список.

Сначала вызовите добавление для нового имени и для уже существующего, затем передайте обновлённый
список функции отбора. Выведите оба списка после фильтрации. Например, к `["Alice", "Ben"]`
добавьте `"Anna"` и `"Alice"`, затем отберите имена на `"a"`.

## Пример вывода

```text
Guests starting with A: ['Alice', 'Anna']
All guests: ['Alice', 'Ben', 'Anna']
```
