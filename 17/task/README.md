# Задание 17. Три счётчика

В файле `main.py` создайте функцию: `count_signs(values)`.

Функция возвращает три количества в таком порядке: положительные, отрицательные, нулевые элементы переданного списка чисел. Исходный список не меняется. Распакуйте результат одного вызова в три переменные и выведите каждое количество с пояснением. Для пустого списка все количества равны нулю. Например, для [4, -2, 0, 7, -1, 0] получится по два элемента каждого вида.

## Пример вывода

```text
Positive: 2
Negative: 2
Zero: 2
```
