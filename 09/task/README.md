# Задание 09. Возврат по условию

В файле `main.py` создайте функцию: `is_negative(number)`.

Функция возвращает True, если число отрицательное, и False в остальных случаях. Используйте вызов функции непосредственно в условии и выведите понятное сообщение на английском. Покажите работу с отрицательным числом, нулём и положительным числом.

## Пример вывода

```text
Check -4: negative
Check 0: not negative
Check 7: not negative
```
