# Задание 14. Приветствие по умолчанию

В файле `main.py` создайте функцию: `make_greeting(name="Guest")`.

Функция возвращает приветствие на английском, содержащее переданное имя. Если аргумент пропущен, используйте имя Guest. Текст приветствия выберите сами. Получите и выведите вне функции результаты вызовов без аргумента и с другим именем.

## Пример вывода

```text
Greeting: Hello, Guest!
Greeting: Hello, Alice!
```
