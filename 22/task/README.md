# Задание 22. Разделение счёта

В файле `main.py` создайте функцию: `split_bill(total, people, tip=10)`.

Функция возвращает сумму на одного человека: сначала к общему счёту добавляются чаевые, затем сумма делится поровну между людьми. total — неотрицательный счёт, people — число людей, целое и не меньше 1, tip — неотрицательный процент чаевых, по умолчанию 10. Сравните расчёты с умолчанием и другой ставкой. Для счёта 100 и четырёх человек при 10% получится 27.5, при 20% — 30. Функция не округляет результат. Округлять можно при выводе.

## Пример вывода

```text
Default tip per person: 27.50
Custom tip per person: 30.00
```
