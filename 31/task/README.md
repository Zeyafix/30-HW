# Задание 31. Учёт расходов

В файле `main.py` создайте функцию: `summarize_expenses(expenses)`.

Функция по списку неотрицательных трат возвращает общую сумму и количество покупок, именно в таком порядке. Каждая запись — отдельная покупка, включая нулевую трату, повторы учитываются. Исходный список не меняется. Распакуйте результат и выведите отчёт. Покажите также случай без покупок: сумма и количество равны нулю. Для [12.5, 7.5, 12.5] общая сумма 32.5, покупок 3.

## Пример вывода

```text
Total spent: 32.5
Purchases: 3
Empty total: 0
Empty purchases: 0
```
