# Задание 11. Удвоить весь список

В файле `main.py` создайте функцию: `double_values(values)`.

Функция удваивает каждый элемент исходного списка чисел. После вызова выведите этот список. Проверьте список [2, -3, 0, 1.5] и пустой список: он должен остаться пустым без ошибки. Возвращаемое значение не требуется.

Данные для показанных вызовов задайте в программе; ввод с клавиатуры не нужен.
Имена, комментарии и текст в коде пишите на английском. Вывод сопровождайте английскими
подписями или понятными сообщениями. Формулировки выбирайте сами: текст примера — один
из возможных вариантов, дословное совпадение не требуется.

## Пример вывода

```text
Doubled values: [4, -6, 0, 3.0]
Empty values: []
```
