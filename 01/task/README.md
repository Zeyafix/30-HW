# Задание 01. Короткий совет

В файле `main.py` создайте функцию: `show_tip()`.

Создайте функцию без параметров, которая выводит короткий полезный совет на английском. Текст совета выберите сами. После определения вызовите функцию один раз.

## Пример вывода

```text
Tip: Save your work often.
```
