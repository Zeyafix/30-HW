# Задание 05. Именованные аргументы

В файле `main.py` создайте функцию: `show_profile(name, city)`.

Функция принимает обязательные имя и город и выводит оба значения с пояснениями. Вызовите её два раза с аргументами по имени: сначала укажите name, затем city; во втором вызове укажите city перед name. Используйте одинаковые данные, чтобы сравнить результат.

## Пример вывода

```text
Name: Alice; city: Baku
Name: Alice; city: Baku
```
