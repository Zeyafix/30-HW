# Задание 23. Пополнить список покупок

В файле `main.py` создайте функцию: `add_product(products, product)`.

Функция добавляет товар в конец переданного списка, если такого названия ещё нет. Меняется исходный список. Названия на английском сравниваются точно: Milk и milk — разные названия. Существующие элементы и их порядок сохраняются, возвращаемое значение не требуется. Вызовите функцию несколько раз, включая повтор уже добавленного товара, и покажите список после вызовов. Например, к ["bread"] добавьте milk, ещё раз milk, затем apples. Пустой список тоже допустим.

## Пример вывода

```text
Shopping list: ['bread', 'milk', 'apples']
```
