# Задание 16. Два соседних числа

В файле `main.py` создайте функцию: `get_neighbors(number)`.

Функция принимает целое число и возвращает два значения в таком порядке: предыдущее число, затем следующее. Сохраните весь результат одного вызова в одной переменной и выведите его с пояснением. Например, у числа 8 соседи 7 и 9. В этой задаче результат хранится целиком, без распаковки.

## Пример вывода

```text
Neighbors: (7, 9)
```
