# Задание 15. Увеличить число

В файле `main.py` создайте функцию: `increase(number, step=1)`.

Функция возвращает число, увеличенное на step. Параметр number обязательный, step по умолчанию равен 1. Сравните результаты двух вызовов для одного числа: с пропущенным и заданным шагом. Шаг может быть положительным, отрицательным или нулевым. Для числа 10 и шага 5 примеры ниже.

Данные для показанных вызовов задайте в программе; ввод с клавиатуры не нужен.
Имена, комментарии и текст в коде пишите на английском. Вывод сопровождайте английскими
подписями или понятными сообщениями. Формулировки выбирайте сами: текст примера — один
из возможных вариантов, дословное совпадение не требуется.

## Пример вывода

```text
Default step: 11
Custom step: 15
```
