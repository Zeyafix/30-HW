# Задание 32. Диапазон температур

В файле `main.py` создайте функцию: `get_temperature_range(temperatures)`.

Функция по непустому списку температур возвращает минимум, максимум и разницу между максимумом и минимумом, именно в таком порядке. Показания могут быть отрицательными и дробными. Исходный список не меняется. Распакуйте результат одного вызова и выведите три значения отдельно. Для [-3, 7, 2] получится -3, 7 и 10. Для единственного показания минимум и максимум совпадают, разница равна нулю. Обработка пустого списка не требуется.

## Пример вывода

```text
Minimum temperature: -3
Maximum temperature: 7
Temperature range: 10
```
