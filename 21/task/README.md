# Задание 21. Покупка со скидкой

В файле `main.py` создайте функцию: `get_purchase_total(price, quantity, discount=0)`.

Функция возвращает итоговую стоимость покупки по цене одной вещи, количеству и скидке в процентах. Скидка применяется ко всей стоимости, по умолчанию она равна 0. Цена неотрицательная, количество — целое число от нуля, скидка — от 0 до 100 включительно. Покажите вызовы с пропущенной и заданной скидкой. Для цены 25 и количества 4 без скидки получится 100, со скидкой 20% — 80. Функция не округляет результат. При выводе можно оставить два знака после точки.

## Пример вывода

```text
Without discount: 100.00
With discount: 80.00
```
