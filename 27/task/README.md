# Задание 27. Покупки в пределах бюджета

В файле `main.py` создайте функцию: `get_affordable(prices, budget)`.

Функция возвращает новый список цен, каждая из которых не превышает budget — доступную сумму на одну покупку. Это отбор отдельных цен, а не подбор корзины по общей сумме. Цены и бюджет неотрицательные. Сохраняйте порядок и повторы, исходный список не меняйте. При отсутствии совпадений, в том числе для пустого списка, возвращайте новый пустой список. Вызовите функцию и покажите результат и исходные цены. Для [12, 5, 10, 5] и бюджета 10 пример ниже.

## Пример вывода

```text
Affordable prices: [5, 10, 5]
Original prices: [12, 5, 10, 5]
```
