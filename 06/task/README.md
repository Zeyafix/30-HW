# Задание 06. Смешанный вызов

В файле `main.py` создайте функцию: `show_item(name, price, quantity)`.

Функция принимает название товара, цену и количество и выводит все три значения с пояснениями. Все параметры обязательные. Вызовите функцию: название передайте позиционно, цену и количество — по имени. Например, товар Notebook, цена 4.5, количество 3.

## Пример вывода

```text
Item: Notebook; price: 4.5; quantity: 3
```
