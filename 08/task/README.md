# Задание 08. Результат в вычислении

В файле `main.py` создайте функцию: `add(first, second)`.

Функция возвращает сумму двух обязательных параметров. Используйте результат её вызова в дальнейшем арифметическом выражении и выведите итог вне функции. Например, сложите 4 и 6 с помощью функции, а полученную сумму умножьте на 3: итог 30.

## Пример вывода

```text
Final result: 30
```
