# Задание 18. Памятка перед выходом

В файле `main.py` создайте функцию: `show_checklist()`.

Создайте функцию без параметров, которая выводит короткий список вещей, которые нужно взять с собой: не меньше трёх вещей на английском. Состав памятки выберите сами. Покажите её вызов для двух разных дней: перед каждым вызовом выведите название дня на английском. Памятка в оба дня одинаковая.

## Пример вывода

```text
Day: Monday
Take: keys, phone, water
Day: Friday
Take: keys, phone, water
```
