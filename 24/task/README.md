# Задание 24. Замена блюда

В файле `main.py` создайте функцию: `replace_dish(menu, old_dish, new_dish)`.

Функция заменяет все вхождения old_dish на new_dish в исходном списке меню. Названия на английском сравниваются точно, с учётом регистра. Порядок и остальные блюда сохраняются. Если совпадений нет или меню пустое, список остаётся прежним. Возвращаемое значение не требуется. Покажите вызов и изменённое меню с повторяющимся блюдом: замените soup на salad в ["soup", "pasta", "soup"].

## Пример вывода

```text
Updated menu: ['salad', 'pasta', 'salad']
```
