# Задание 10. Изменить первый элемент

В файле `main.py` создайте функцию: `replace_first(values, new_value)`.

Функция меняет первый элемент переданного непустого списка на new_value. Остальные элементы остаются прежними. После вызова выведите исходный список, чтобы увидеть изменение. Например, список [5, 8, 11] и новое значение 99 дают [99, 8, 11]. Обрабатывать пустой список в этой задаче не нужно. Возвращаемое значение не требуется.

## Пример вывода

```text
Updated values: [99, 8, 11]
```
