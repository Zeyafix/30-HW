# Задание 07. Вернуть куб числа

В файле `main.py` создайте функцию: `cube(number)`.

Функция возвращает куб переданного числа. Сохраните результат вызова в переменную и выведите её значение вне функции. Например, для 3 получится 27. Проверьте также отрицательное число и ноль.

## Пример вывода

```text
Cube: 27
Negative cube: -8
Zero cube: 0
```
