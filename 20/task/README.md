# Задание 20. Стоимость поездки

В файле `main.py` создайте функцию: `get_trip_cost(distance, consumption, fuel_price)`.

Функция возвращает стоимость топлива для поездки. distance — расстояние в километрах, consumption — расход в литрах на 100 км, fuel_price — цена литра. Все три параметра обязательные. Значения неотрицательные, возможны дробные. Сравните две поездки, вызвав функцию для каждой и выведя стоимости вне функции. Для 150 км, расхода 8 и цены 1.5 стоимость равна 18; для 240 км при том же расходе и цене — 28.8. Внутри функции не округляйте результат. При выводе можно округлить до двух знаков после точки.

## Пример вывода

```text
First trip cost: 18.00
Second trip cost: 28.80
```
